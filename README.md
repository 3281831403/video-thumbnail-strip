# video-thumbnail-strip

## 题面

素材库给每个视频生成缩略图条后，末尾总少一帧、人脸还被切掉：均匀取样用整数除法，末尾缩略图偏移 1 帧；关键帧取样不吸附，取到非关键帧解码失败；布局按行优先但列数不校验，最后一行溢出画布；合成不做边界裁剪，越界索引报错；时间码毫秒不进位，999.6 显示 999；缩放不保持等比，缩略图被拉扁；居中裁切用左上角，人脸被切掉；校验不查重叠，缩略图互相覆盖；批量共用画布，视频之间叠加；count=0 不校验，除零。thumbs/strip.py 是核心，tests/test_strip.py 15个红。要修的是：把上述 10 个缺陷全部修掉，并让 15 条测试转绿。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始状态必须恰好是 `15 failed`，且没有 collection error、import error 或 syntax error；修复后应全部通过。

## 约束

`tests/test_strip.py` 不可修改，评测以该文件为准。实现只使用 Python 标准库（`math`、`bisect`），离线运行，不使用随机数和 `sleep`。时间单位为毫秒，帧号从 0 开始，时间/帧号比较允许 1 帧容差。
